## 🚀 About Sigma 8.0

**Sigma 8.0** is Apna College’s flagship placement preparation course, designed for aspiring software developers. The curriculum combines:

- **Complete Web Development (MERN Stack)**
  - Frontend: HTML, CSS, JavaScript, React
  - Backend: Node.js, MongoDB, SQL
  - Projects: Zerodha, Airbnb, Zoom, LinkedIn, ChatGPT, and more
  - Version Control: Git & GitHub
  - Advanced modules: Docker, Kubernetes, WebRTC, AWS constructs

- **Data Structures & Algorithms (DSA)**
  - Core DSA in Java (with optional C++)
  - Advanced DSA topics
  - 50+ live practice sessions with MAANG engineers
  - 300+ coding questions from top companies

- **Placement Preparation**
  - Quantitative aptitude
  - Resume building and LinkedIn optimization
  - Mock interviews and career guidance
  - Direct placement opportunities with partner companies

- **Mentorship & Community**
  - Individual doubt support from TAs
  - Access to an active student community
  - 1:1 resume correction with mentors

**Duration:** 8.5 months

**Instructor:** Shradha Khapra (Ex-Microsoft SDE)
