To add condition in group by clause -> we use having condition
select age,max(followers) from user GROUP BY age having max(followers) > 200;

General Order:
SELECT column(s)
FROM table_name
WHERE condition
GROUP BY column(s)
HAVING condition
ORDER BY column(s) ASC;


EG: select age,max(followers) from user GROUP BY age having max(followers) > 200 order by age DESC;
