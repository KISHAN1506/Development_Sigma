docker pull IMAGE_NAME -> to get the image from dockerhub
docker images
docker run IMAGE_NAME -> to make a container of the docker
docker run -it IMAGE_NAME -> open in interactive mode
docker stop CONT_NAME or CONT_ID -> stop pre existing container
docker start CONT_NAME or CONT_ID -> start pre existing container
docker ps -> just to see the currently  running containers
docker ps -a -> to see all the container current status
